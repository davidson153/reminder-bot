# Telegram-бот напоминалка без своего сервера

Бот живёт на **Cloudflare Workers** (бесплатный тариф). Это не сервер, который нужно держать включённым: Cloudflare сам запускает код, когда приходит сообщение, и раз в минуту по расписанию. Поэтому бот работает круглосуточно, даже когда твой компьютер выключен.

- `worker.js` - весь код бота
- `wrangler.toml` - настройки (база, расписание раз в минуту)

## Как это устроено

1. Ты пишешь боту -> Telegram пересылает сообщение на адрес воркера (`/webhook`) -> воркер разбирает время и сохраняет напоминание в базу D1 (это SQLite у Cloudflare).
2. Раз в минуту Cloudflare запускает воркер по cron -> воркер берёт из базы всё, у чего подошло время, и отправляет тебе.
3. Схема напоминаний: заранее (за день / 3 часа / час / 15 минут, выбираешь кнопками) -> в момент события -> повторы каждые N минут, пока не нажмёшь «Готово» (или пока не кончится лимит повторов). Есть кнопки «отложить на 10 минут / час / сутки».

## Что нужно

- аккаунт Cloudflare (бесплатный, карта не нужна): https://dash.cloudflare.com/sign-up
- Node.js LTS (для команды `npx wrangler`): https://nodejs.org
- Telegram

**Важно для России:** провайдеры замедляют Cloudflare, поэтому сайт Cloudflare и команды `wrangler` могут не работать без VPN. Нужен он только на время настройки. Самому боту блокировка не мешает: Telegram и Cloudflare общаются между собой за пределами РФ.

## Установка (10-15 минут)

### 1. Создай бота
В Telegram открой @BotFather -> `/newbot` -> придумай имя -> получишь **токен** вида `123456:ABC-DEF...`.

### 2. Придумай секрет
Это пароль, по которому воркер отличает настоящий Telegram от чужих запросов. Разрешены только латиница, цифры, `_` и `-`. Проще сгенерировать:
```
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

### 3. Войди в Cloudflare и создай базу
Открой терминал в папке с `worker.js` и `wrangler.toml`:
```
npx wrangler login
npx wrangler d1 create reminders
```
Вторая команда выведет `database_id`. Вставь его в `wrangler.toml` вместо `ВСТАВЬ_СЮДА_ID_БАЗЫ`.

### 4. Загрузи бота
```
npx wrangler deploy
```
Если аккаунт новый, wrangler попросит придумать поддомен workers.dev. В конце он покажет адрес вида `https://reminder-bot.ТВОЙ-ПОДДОМЕН.workers.dev`.

### 5. Добавь токен и секрет
```
npx wrangler secret put BOT_TOKEN
npx wrangler secret put WEBHOOK_SECRET
```
Каждая команда попросит вставить значение (токен из шага 1, секрет из шага 2). В коде и в `wrangler.toml` их нет, поэтому проект можно спокойно выкладывать на GitHub.

### 6. Подключи вебхук
Открой в браузере:
```
https://reminder-bot.ТВОЙ-ПОДДОМЕН.workers.dev/setup?key=ТВОЙ_СЕКРЕТ
```
Должно быть `Таблицы: OK` и `setWebhook: {"ok":true,...}`. Всё, пиши боту `/start`.

### 7. (Желательно) Закрой бота от чужих
Бот покажет твой ID в `/start`. Впиши его в `wrangler.toml`:
```
[vars]
ALLOWED_USERS = "123456789"
```
и снова `npx wrangler deploy`. Можно несколько ID через запятую. Без этого любой, кто найдёт бота, сможет им пользоваться (напоминания у каждого свои, чужие он не увидит).

## Вариант без Node.js (через сайт Cloudflare)

1. Workers & Pages -> Create -> создай Worker с именем `reminder-bot`, открой редактор кода, вставь весь `worker.js`, Deploy.
2. Storage & Databases -> D1 -> создай базу `reminders`.
3. В настройках воркера (Settings):
   - Bindings -> добавить D1 database, имя переменной `DB`, база `reminders`;
   - Variables and Secrets -> два секрета `BOT_TOKEN` и `WEBHOOK_SECRET`;
   - Triggers -> Cron Triggers -> `* * * * *` (каждую минуту).
4. Открой `/setup?key=ТВОЙ_СЕКРЕТ`, как в шаге 6.

Названия пунктов меню у Cloudflare иногда меняются, но разделы те же.

## Как пользоваться

Просто пиши, когда и о чём напомнить. Время может быть в начале или в конце:
```
через 20 минут выключить чайник
через 1ч 30м позвонить домой
в 18:30 тренировка
завтра в 9:00 пара по физике
послезавтра в 7 вечера кино
28.10 12:00 сдать лабу
5 ноября 10:00 зачёт
в пятницу 15:00 забрать посылку
каждый день 8:00 выпить витамины
по будням 7:30 подъём
каждый пн 10:00 планёрка
позвонить домой завтра в 15:00
```
Команды: `/list` (список и удаление), `/settings` (что ставить по умолчанию), `/tz +3` (часовой пояс), `/help`.

## Если что-то не работает

- **Логи:** `npx wrangler tail` (смотреть в реальном времени) или вкладка Logs воркера на сайте Cloudflare.
- **Бот молчит:** открой `/setup?key=...` ещё раз и посмотри, что ответил `setWebhook`.
- **`forbidden` на /setup:** секрет в адресе не совпадает с `WEBHOOK_SECRET`.
- **Обновить бота:** поменял `worker.js` -> `npx wrangler deploy`. Напоминания в базе сохраняются.

## Ограничения бесплатного тарифа

- 100 000 запросов в день (cron тратит 1440, остальное твои сообщения) - хватит с огромным запасом;
- 10 мс процессорного времени на запуск: разбор даже длинного сообщения занимает меньше 1 мс;
- база D1: 5 млн чтений и 100 тыс. записей в день;
- точность напоминаний около минуты (cron раз в минуту).
